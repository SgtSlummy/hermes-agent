# Tarot Router quickstart moved

The product formerly called Occult System is now **Tarot Router**.

Use the authoritative
[Tarot Router local public v1 quickstart](../tarot-router/quickstart.md).

The `docs/occult` path remains as a compatibility location for v1 release
notes and operations material. Existing `occult` commands, `/v1/occult/*` API
paths, `OCCULT_*` environment variables, state paths, and signed asset names
remain supported.
