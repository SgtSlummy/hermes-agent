# Tarot Router v1.0.9

Tarot Router v1.0.9 is the full-Major-Arcana deployment patch. It bundles all
22 signed Major Arcana starter packages, the secret-free provider catalog, the
gateway control room, and setup-gated OpenAI Codex model selection.

It pins the signed Agents Council `v0.5.6` release, which contains the complete
22-card Council spread example. Runtime contract `1.0.0`, Council state schema
3, local-first routing, and the fail-closed provider policy remain unchanged.

External providers still require legitimate operator authorization. No
credentials are embedded in the release or exposed to agents.
